# Discord Модераційний Бот (moder.js)

Бот для модерації серверу Discord на **Node.js (JavaScript)** з інтерактивною панеллю дій модератора через слэш-команду `/acation`.

---

## 📋 Можливості бота

### 1. Команда `/acation`
Відкриває панель керування користувачем:
* **Інформація:**
  * Нікнейм
  * Discord ID
  * Дата входу на сервер
  * Аватарка користувача
* **Кнопки модерації (Ряд 1):**
  * `Выдать пред` — відкриває вікно для введення причини та додає попередження
  * `Выдать варн` — відкриває вікно для введення причини та додає догану
  * `Выдать мут` — вікно введення часу (наприклад: `10m`, `1h`, `1d`) та причини (Discord Timeout + ролі)
  * `Выдать бан` — вікно введення причини та видача бану
* **Кнопки зняття покарань (Ряд 2):**
  * `Снять пред` — знімає останній пред
  * `Снять варн` — знімає останній варн
  * `Снять мут` — знімає таймаут та мут-ролі
  * `Снять бан` — розбанює користувача
* **Керування ролями (Ряд 3):**
  * `Сменить гендер` — перемикання між 🩵 та 🩷
  * `Верифицировать` — знімає роль `unvefiry`
  * `Выдать недопуск` — видає роль `Недопуск`
  * `Снять недопуск` — знімає роль `Недопуск`
* **Додаткові дії (Ряд 4):**
  * `Выдать отстранение` — видає роль `Отстранение`
  * `Снять отстранение` — знімає роль `Отстранение`
  * `Выдать креативную роль` — перемикає роль `Creative`
* **Скасування (Ряд 5):**
  * `Отмена` — скасовує та закриває панель

### 2. Команди персоналу `/staff` (усі через слеш, без нижніх підкреслень)
* **`/staff profile [user]`** — показує детальний профіль співробітника (посади/ролі, дата входу, статус ЧС, статистика дій за тиждень та наявні догани).
* **`/staff actions [moderator]`** — статистика активності модератора за поточний тиждень (дій модератора, саппорта, клозера, креатива).
* **`/staff manage [user]`** — панель управління персоналом для ролі **Master** та вище:
  * `Выдать пред`, `Выдать варн`, `Выдать мут`, `Выдать бан`
  * `Кикнуть` — кік користувача з сервера з причиною
  * `В Черный Список` — додавання в базу ЧС, зняття всіх звичайних ролей (зберігаються в БД для відновлення) та видача ролі `Черный Список`. Користувачу блокується доступ до всіх каналів, залишається лише канал `#апиляцію`!
  * `Снять ЧС` — видалення з ЧС, зняття ролі `Черный Список` та автоматичне відновлення попередніх ролей користувача.
  * `Снять пред`, `Снять варн`, `Снять мут`, `Снять бан`
  * `Снять роли стаффа` — швидке зняття всіх посад/ролей персоналу (derank) в 1 клік
  * **Випадаюче меню ролей:** список усіх поточних ролей користувача для швидкого зняття будь-якої конкретної ролі!
  * Захист від зловживань: модератор не може керувати користувачем із рівною або вищою роллю.

### 4. Система Чорного Списку та Апеляцій
* **Повне блокування:** при внесенні в ЧС бот знімає з порушника всі ролі та видає роль `Черный Список`.
* **Доступ тільки до каналу апеляцій:** у всіх категоріях серверу для цієї ролі вимкнено перегляд каналів (`ViewChannel: false`). Відкрито доступ **виключно** до каналу **`#апиляцію`**.
* **Кнопка `[📝 Подати апеляцію]`:** у каналі `#апиляцію` знаходиться інтерактивна панель. При натисканні відкривається форма, де порушник пише пояснення ситуації та обіцянки.
* **Розгляд заявок персоналом:** заповнена апеляція автоматично надходить у канал **`#log1`** із двома кнопками для стаффу (Master і вище):
  * `[✅ Схвалити]` — знімає ЧС, автоматично повертає всі попередні ролі учаснику та надсилає йому радісне повідомлення в ОП.
  * `[❌ Відхилити]` — відкриває вікно для введення причини відхилення та сповіщає порушника в ОП.
* **Команда `/appeal`:** оновлює панель апеляцій та примусово синхронізує права каналів у разі створення нових категорій.

### 5. Система скарг `/report` (для користувачів)
* **`/report user:@порушник [reason] [proof]`** — дозволяє будь-якому учаснику надіслати скаргу на порушника.
  * Якщо причину не вказано в команді, бот відкриє зручне вікно (модалку) для докладного опису та посилання на доказ/скріншот.
* **Канал `🗑️корзина`:** кожна скарга миттєво надходить у канал `🗑️корзина` у вигляді інтерактивної картки:
  * **Голосовий канал порушника:** показує, у якому саме голосовому каналі сидить порушник (або `Не в голосовому каналі`).
  * **Голосовий канал автора:** показує голосовий канал відправника.
  * **Текстовий канал:** фіксує канал, звідки надійшла скарга.
* **Кнопки для модераторів у картці репорту:**
  * **`[✋ Взять репорт]`** — закріплює скаргу за модератором, змінює статус на `🟢 В обработке (Взял: @Модератор)` та сповіщає автора в ОП.
  * **`[⚡ Действие: Нарушитель]`** — миттєво відкриває модераційну панель `/acation` над порушником.
  * **`[⚠️ Действие: Автор]`** — відкриває панель дій над автором скарги (якщо репорт було подано «по приколу» або неправдиво).
  * **`[✅ Закрыть]`** — успішно закриває репорт і надсилає повідомлення автору з подякою.
  * **`[❌ Отклонить]`** — запитує причину відхилення (наприклад, "ложная жалоба / по приколу") і надсилає сповіщення автору в ОП.
* **Логування в `#log1`:** усі події (створення репорту, взяття модератором у роботу, закриття та відхилення) автоматично фіксуються в каналі логів `#log1` із зазначенням нікнеймів та голосових кімнат.

## 🚀 Як запустити бота

1. Двічі клікніть по файлу **`start.bat`** у папці `moder.js`
   * Або у терміналі:
     ```bash
     npm start
     ```
2. Бот увійде у мережу та автоматично зареєструє команди `/acation`, `/staff`, `/appeal`, `/report`.

---

## ⚙️ Важливе налаштування прав у Discord

Щоб бот міг мутити, банити та видавати ролі іншим учасникам:
1. Зайдіть у **Налаштування сервера** -> **Ролі**.
2. Перетягніть роль бота (`moder`) **якнайвище** у списку ролей (вище за звичайних учасників та модераторів, якими бот має керувати).
